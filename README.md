# Works — 나만의 링크트리

작업 중인 프로젝트를 **폴더**로 나눠 모아 두고, 폴더마다 독립된 공개 페이지를 갖는 링크 허브입니다.

- **관리자 화면** `/admin` — 폴더 만들기, 링크 등록, 글 작성, 순서 변경, 공개/비공개 전환
- **방문자 화면** `/`, `/폴더주소`, `/폴더주소/글ID` — 로그인 없이 누구나 볼 수 있는 페이지

| 구분 | 담고 있는 것 |
| --- | --- |
| 폴더 | 폴더명, 한 줄 설명, 썸네일, **테마 컬러**, 링크 여러 개(인스타·유튜브·틱톡 등), 소개글, 조회수 |
| 글 | 제목, 링크 여러 개, 사진 여러 장, 소개, 조회수 |

디자인은 **Toss(TDS Mobile) 규칙**을 따릅니다. 버튼 사이즈 스케일(32/38/48/56px · 8/10/14/16px 라운드), 채움·약한 채움 두 가지 버튼 타입, 회색 채움 입력 필드, 로딩 중에도 버튼 폭을 유지하는 규칙까지 그대로 반영했습니다.

기술 스택: Next.js 15 (App Router) · TypeScript · Tailwind CSS 4 · lucide-react · Supabase (Postgres + Storage)

---

## 1. Supabase 준비 (최초 1회)

1. [supabase.com](https://supabase.com) 에서 프로젝트를 만듭니다. (무료 플랜으로 충분)
2. 좌측 **SQL Editor** 를 열고 [`supabase/schema.sql`](supabase/schema.sql) 내용을 통째로 붙여넣은 뒤 **Run**.
   → 테이블 2개(`folders`, `posts`)와 이미지 저장용 `media` 버킷이 만들어집니다.
3. 값 3개를 복사합니다. Supabase 가 최근 키 이름을 바꿔서 **프로젝트 생성 시기에 따라 화면이 다릅니다.**

   **주소 + 공개 키** — 프로젝트 화면 위쪽 초록색 **Connect** 버튼 → **App Frameworks** 탭 → **Next.js**
   여기에 `NEXT_PUBLIC_SUPABASE_URL` 과 공개 키가 복사할 수 있게 나옵니다.

   **비밀 키** — 좌측 하단 톱니바퀴(**Project Settings**) → **API Keys**
   - `Secret keys` 항목의 값 (`sb_secret_…`) — 없으면 **Legacy API Keys** 탭의 `service_role` 값
   - ⚠️ 이건 **절대 외부에 공개하면 안 되는 키**입니다. GitHub 에도 올라가지 않습니다.

## 2. 로컬에서 실행

```bash
npm install
```

프로젝트 폴더에 있는 **`.env.local` 파일을 메모장이나 편집기로 열어** 값을 채웁니다.
(따로 만들 필요 없이 이미 들어 있고, git 에는 올라가지 않습니다. 파일 안에 어디서 복사하는지도 적어 뒀습니다)

```
NEXT_PUBLIC_SUPABASE_URL=https://xxxx.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=sb_publishable_...   ← 또는 예전 anon key
SUPABASE_SERVICE_ROLE_KEY=sb_secret_...            ← 또는 예전 service_role key
ADMIN_PASSWORD=원하는-비밀번호
AUTH_SECRET=길고-랜덤한-아무-문자열
```

> 새 이름(`sb_publishable_…` / `sb_secret_…`)과 예전 이름(`anon` / `service_role`) **둘 다 그대로 넣으면 동작합니다.**
> `ADMIN_PASSWORD` 는 지금 `woo1234` 로 들어 있습니다. **반드시 바꾸세요.**
> `AUTH_SECRET` 은 로그인 쿠키 위조를 막는 값이라 길수록 좋습니다.

```bash
npm run dev
```

- 방문자 화면: http://localhost:3000
- 관리자 화면: http://localhost:3000/admin (비밀번호 입력)

환경변수를 바꾸면 **개발 서버를 껐다 켜야** 반영됩니다.

## 쓰는 법

**폴더 만들기** — `/admin` → `+ 새 폴더`
공개 주소(슬러그)는 폴더명에서 자동으로 만들어집니다. 폴더명 아래에 미리보기(`/브랜드-리뉴얼`)가 뜨고, 바꾸고 싶을 때만 `주소 직접 정하기` 를 눌러 펼치면 됩니다. 이미 만든 폴더는 이름을 고쳐도 주소가 따라 바뀌지 않습니다(공유해 둔 링크가 깨지지 않게).

**링크 추가** — 링크 칸 맨 위 입력창에 **주소를 붙여넣으면 그 자리에서 줄이 생깁니다.** 여러 줄을 한꺼번에 붙여넣으면 링크도 한꺼번에 만들어지고, 이미 있는 주소는 알아서 건너뜁니다.
인스타·유튜브·틱톡·X·깃허브 등은 자동으로 인식해 아이콘과 색을 붙입니다. `instagram.com/...` 처럼 `https://` 를 빼고 써도 되고, 표시 이름을 비워 두면 플랫폼 이름이 자동으로 들어갑니다.

**폴더별 테마 컬러** — 폴더 편집 화면의 `테마` 카드
프리셋을 고르거나, 컬러 피커를 쓰거나, **HEX 코드(`#FF6B2C`)를 직접 입력**하면 됩니다. 이 한 색에서 버튼·약한 버튼·배지·아이콘 배경·포커스 링·상단 그라데이션·모바일 브라우저 상단바 색까지 전부 자동으로 만들어집니다(`color-mix()` 파생). 밝은 색(노랑·라임 등)을 넣으면 버튼 글자색이 자동으로 어두운 색으로 바뀝니다. 다크 모드용 톤도 같은 색에서 따로 계산됩니다.

> 이미 `folders` 테이블을 만들어 둔 상태라면 SQL Editor 에서 아래 한 줄만 실행하면 됩니다.
> ```sql
> alter table public.folders add column if not exists theme_color text not null default '#3182f6';
> ```

**글 쓰기** — `/admin` 폴더 줄의 `+ 글` 버튼(바로 열림) 또는 폴더 관리 화면의 `+ 새 글`
사진은 **끌어다 놓거나 `Ctrl/⌘ + V` 로 붙여넣어도** 올라갑니다(캡처한 이미지 바로 붙여넣기). 여러 장 올릴 수 있고 **첫 번째 사진이 목록의 대표 이미지**가 됩니다. 사진 위에 마우스를 올리면(터치 기기에서는 항상) 순서 변경(← →)과 삭제 버튼이 나옵니다.
어느 칸에 있든 **`Ctrl/⌘ + Enter` 로 저장**됩니다. 저장 버튼은 창 아래에 고정돼 있어 끝까지 스크롤할 필요가 없습니다.

**순서 바꾸기** — 목록 왼쪽의 손잡이(⠿)를 잡고 끌어다 놓습니다. 놓는 즉시 저장되고, 방문자 화면에도 그대로 반영됩니다.

**비공개** — 목록의 `공개 / 비공개` 스위치를 누르거나, 편집 화면의 `공개하기` 체크를 끄면 됩니다. 데이터베이스 정책(RLS) 수준에서 막히므로 주소를 알아도 볼 수 없습니다.

**첫 화면 감추기** — `/admin` 맨 위의 `첫 화면 전체 목록` 카드에서 켜고 끕니다.
비공개로 두면 사이트 주소(`/`)로 들어와도 404 가 뜨고, **각 폴더 주소(`/슬러그`)를 아는 사람만** 들어올 수 있습니다. 링크를 아는 사람에게만 공유하고 싶을 때 쓰세요.

**조회수** — 폴더 페이지와 글 페이지가 열릴 때마다 하나씩 올라갑니다. 같은 브라우저에서 새로고침해도 그 세션 안에서는 한 번만 셉니다. 폴더 화면 상단의 `조회` 숫자는 **폴더 조회수 + 그 안의 모든 글 조회수** 합계입니다. (누구나 볼 수 있는 페이지라 정밀한 통계가 아니라 대략의 인기 지표로 보세요)

## 알아둘 점

- 글 삭제 시 그 글의 사진도 Supabase Storage 에서 함께 지워집니다. 폴더를 지우면 안의 글과 사진이 전부 사라집니다.
- 이미지는 장당 최대 10MB, jpg/png/webp/gif/avif 를 지원합니다. 사진 자체는 서버를 거치지 않고 **브라우저에서 Supabase Storage 로 바로** 올라갑니다(서버는 서명 URL만 발급). 그래서 Vercel 함수의 요청 본문 제한(4.5MB)에 걸리지 않고, 여러 장을 올려도 빠릅니다.
- 올릴 때 이미지의 가로·세로를 재서 주소 뒤에 `#1200x800` 형태로 붙여 둡니다. 방문자 화면이 이미지가 뜨기 전에 자리를 미리 잡아 **글이 아래로 밀리지 않게** 하는 용도이고, `#` 뒤는 서버로 전송되지 않아 로딩에는 아무 영향이 없습니다. 크기 표시가 없는 예전 이미지도 그대로 동작합니다.
- 공개 페이지(`/`, `/폴더주소`, `/폴더주소/글ID`)는 빌드 시 미리 만들어져 정적으로 서빙되고 60초마다 갱신됩니다. 대시보드에서 저장하면 즉시 갱신됩니다.
- 관리자 인증은 비밀번호 1개 + 서명된 쿠키(30일) 방식입니다. 비밀번호를 바꾸면 기존 로그인 세션이 모두 무효화됩니다.

## 구조

```
app/
  page.tsx                     전체 폴더 목록 (방문자)
  [slug]/page.tsx              폴더 공개 페이지
  [slug]/[postId]/page.tsx     글 상세 페이지
  login/page.tsx               관리자 로그인
  admin/                       대시보드 (로그인 필수)
  api/upload/route.ts          업로드용 서명 URL 발급 (사진은 브라우저 → Storage 직접 전송)
  globals.css                  디자인 토큰 + 컴포넌트 스타일 (TDS 규칙)
components/                    폼·에디터·갤러리 등 UI
  ThemePicker.tsx              폴더 테마 컬러 선택기
lib/
  actions.ts                   서버 액션 (저장/삭제/정렬)
  queries.ts                   데이터 조회
  auth.ts                      비밀번호 로그인 · 쿠키 서명
  theme.ts                     HEX 정규화 · 프리셋 · 대비 계산
  platform.ts                  URL → 플랫폼 자동 인식
supabase/schema.sql            DB 스키마 (최초 1회 실행)
```
